# Misskeyプラグイン for わんコメ

わんコメで、Misskeyの特定のチャンネルのノートをコメントとして表示するプラグインです。

## 使い方

1. [リリースページ](https://github.com/kakkokari-gtyih/onecomme-misskey-plugin/releases) の最新のリリースを開き、Assets と書かれているところに添付されているZIPファイルをダウンロードします
2. ダウンロードしたZIPファイルを解凍し、わんコメのプラグインフォルダに設置します
3. わんコメを起動し、プラグインを有効化します
4. プラグインの一覧にある「URL」をクリックして設定ページを開きます
5. Misskeyサーバーを入力してログインします（MiAuth）
6. わんコメで枠を追加し、「視聴URL」にMisskeyのチャンネルのページのアドレス（例: `https://misskey.io/channels/xxxxxxxxxx`）を貼り付けます
7. 枠の「接続」をオンにすると、そのチャンネルの新しいノートがその枠のコメントとして追加されます

枠を複数追加すると、複数のチャンネルを同時に連携できます（ログイン中のサーバーのチャンネルのみ）。

## FAQ

### Q: 複数のチャンネルを同時に連携できますか？
A: はい、枠を複数追加することで、複数のチャンネルを同時に連携できます。ただし、わんコメ側の同時接続数制限があります。

### Q: 複数のサーバーのチャンネルを同時に連携できますか？
A: いいえ、プラグインでログイン中のサーバーのチャンネルのみ連携可能です。別のサーバーにあるチャンネルに切り替える場合は、プラグイン側で一度ログアウトし、別のサーバーにログインしなおす必要があります。

### Q: プラグインの設定画面は常に表示していないといけませんか？
A: いいえ、プラグインの設定画面は常に表示している必要はありません。一度ログインなどの設定を済ませば、わんコメの画面上で操作を行うことができます。
